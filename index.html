SYSTEM FAQ

PROXY NOT WORKING?

Ensure you have a Wisp server running. Enter your Wisp WebSocket URL in the browser toolbar's Wisp panel (e.g., wss://your-server.com/wisp/). The Scramjet service worker must be registered at /scram/sw.js.

GAMES WON'T LOAD

Some games require external CDN access. If a game fails to load, check your network connection or try a different title. The game player uses sandboxed iframes with base tag injection for relative asset loading.

HOW DO I ADD CUSTOM APPS?

Currently, apps are built into the system. Future versions will support a plugin API for sideloading custom applications.

SPOTIFY NOT PLAYING

Spotify uses iTunes preview clips (30 seconds each). This is a demo integration. Search for songs and double-click to play. Playlists are saved in localStorage.

PERFORMANCE TIPS

Enable "Optimized Background" in Settings to disable video backgrounds. Clear your browser cache if the system feels sluggish. The FPS counter in the top-right shows real-time performance.
